> Nenáročný CLI nástroj pro monitoring Raspberry Pi — zobrazuje teplotu CPU, využití RAM a dobu běhu systému.

[![Typing SVG](https://readme-typing-svg.demolab.com?font=Geom&size=50&pause=1000&width=435&lines=Instalace)](https://git.io/typing-svg)
> 1. Projekt se nachází v Alpha stavu prvně potřebujete na váš raspberryPI server nainstalovat Golang. [Viz](https://go.dev/dl/)
> 2. Jakmile instalace proběhne úspěšně naklonujte tento projekt z repozitáře a následně vlezte do pimonitor složky
> 3. Jakmile vlezete do pimonitor složky stačí zadat `go build` a projekt se vám převede do exe programu.

```bash
git clone https://github.com/tvůj_username/pimonitor
cd pimonitor
go build
./pimonitor
```

> Posledním příkazem spustíte program.
> [!NOTE]
> V budoucnu se očekává automatická instalace pro *ARM* procesory.
